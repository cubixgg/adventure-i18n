# Security Policy

## Supported versions

No release has been published yet (see [`roadmap.md`](./docs/roadmap.md) for implementation status).
Once `adventure-i18n` starts publishing releases, only the most recently published version will
receive security fixes — there's no LTS branch planned.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a security vulnerability. Instead, use GitHub's
private vulnerability reporting: on this repo's **Security** tab, select **Report a vulnerability**.
That opens a private advisory visible only to maintainers.

Include, where you can:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal repro lang bundle + translator setup is ideal)
- The `adventure-i18n` version and Adventure/MiniMessage version involved

We'll acknowledge reports as promptly as we can and work with you on a fix and disclosure timeline
before anything is made public.
